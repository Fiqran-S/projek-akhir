HTML (Hypertext Markup Language) adalah bahasa dasar untuk membangun struktur web seperti text, gambar, tombol, input, video/audio, dll.

HTML adalah bahasa kerangka dasar dari suatu web.

CSS (Cascading Style Sheet) adalah bahasa untuk memberikan style atau gaya pada website baik dari segi warna, font, ukuran, layout, dan yang berhubungan mengubah tampilan.

CSS adalah bahasa yang tampilan website yang biasa memiliki warna dan gaya.
